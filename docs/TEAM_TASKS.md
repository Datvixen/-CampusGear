# CampusGear Team Tasks

## Project
CampusGear - Campus Equipment Inventory System

All team members will work from the same GitHub repository. Each team member should work on their assigned section and make meaningful GitHub commits.

---

## Person 1 - Backend & Database Lead

Responsibilities:

- Maintain the Flask project structure
- Create and manage the SQLite database
- Create necessary database tables
- Build Add Equipment functionality
- Build Edit Equipment functionality
- Build Delete Equipment functionality
- Connect equipment forms to the database
- Help implement login/authentication
- Make sure backend routes work correctly

Suggested branch:

backend-database

---

## Person 2 - Checkout & Dashboard Lead

Responsibilities:

- Build equipment checkout functionality
- Build equipment return functionality
- Store borrower information
- Store checkout and due dates
- Create overdue equipment logic
- Create checkout history
- Build dashboard totals and statistics
- Update equipment status when checked out
- Update equipment status when returned

Suggested branch:

checkout-dashboard

---

## Person 3 - Frontend, Search & Testing Lead

Responsibilities:

- Build and style application pages
- Create consistent navigation
- Style equipment forms
- Style equipment tables
- Add status badges
- Build equipment search
- Build category filters
- Build condition filters
- Build location/status filters
- Add user-friendly validation and error messages
- Write automated tests
- Test major application functionality
- Help fix frontend errors

Suggested branch:

frontend-search-testing

---

## Team Integration

All three sections will be combined into the main CampusGear application.

Before merging work into main:

1. Make sure the application runs.
2. Test the new functionality.
3. Commit changes to your branch.
4. Push the branch to GitHub.
5. Review changes before merging into main.
6. Make sure another team member's work was not accidentally removed.
